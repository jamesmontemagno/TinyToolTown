I maintain Codex Quota Overlay, an independent MIT-licensed desktop utility for people using Codex Desktop. It shows quota, reset timing, and credits only while Codex is in the foreground, using the documented local Codex App Server method. It does not capture screenshots, window titles, browser cookies, or API keys. The Windows build has been verified on physical Windows 11 hardware; macOS release artifacts and automated checks are available, while physical-Mac acceptance remains pending. The project is community-maintained and is not affiliated with or endorsed by OpenAI.
