GSC Opportunity Analyzer turns Google Search Console CSV exports into a deterministic SEO triage queue. It identifies striking-distance queries, site-relative CTR gaps, rising demand, decay, and page opportunities without uploading search data or making network requests. I built it to turn large exports into a small, evidence-backed work queue while keeping sensitive query and URL data local. It works as a zero-runtime-dependency CLI, GitHub Action, npm package, and browser tool.
