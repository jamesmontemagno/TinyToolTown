I built the tool to help out to reduce unnecessary tokens used. Instead of bloating your context with all tools at first prompt, load instructions for tools when they are required.
This is not an unique idea but this is .NET written tool running as an MCP instead not CLI. Download as nuget or download native AOT compiled binaries from the github page.
