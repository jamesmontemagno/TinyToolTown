MemPalace Viewer renders an AI memory system (MemPalace) as an interactive 3D blueprint. Wings become floors, rooms become spaces, and memories become objects you can walk through. Built with Three.js, it lets you visualize how an AI organizes knowledge — connections between concepts rendered as glowing tunnels between rooms. Originally built to understand my own AI assistant's memory architecture, but works with any MemPalace instance. It's like walking through the mind of an AI.
