OPNsense Widget is a MacOS desktop app that puts your OPNsense firewall’s interface status, link speed, IP, MAC, up/down state, and real-time bandwidth graphs, right in your system tray, no browser login required. I built it because I got tired of constantly tabbing into the OPNsense web UI just to check if a link was flapping or a connection was saturated; I wanted a glanceable, always-on dashboard that lives at the edge of my screen. What makes it delightful is the attention to detail: the Catppuccin Mocha dark theme, the buttery-smooth live bandwidth sparklines that show traffic at a glance, the drag-free reordering, custom interface labels, and the way it remembers exactly where you left it, it transforms a utilitarian monitoring task into something you actually enjoy having visible.
