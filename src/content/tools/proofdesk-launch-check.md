ProofDesk Launch Check gives a public web page a quick, reproducible pre-launch baseline without an account, dashboard, telemetry, or package install. One Node.js file checks reachability, redirects, HTTPS, metadata, initial HTML, image alt attributes, bounded same-origin links, robots, and sitemap, then produces readable Markdown or structured JSON. It stays deliberately small, labels its limitations, includes tests, and reminds users to verify every finding before contacting a maintainer.
