Public Issue Evidence Capsule is a zero-dependency, read-only GitHub Action that records selected issue metadata, activity, timeline event counts, linked public pull request references, and explicit API coverage gaps. It never clones or executes target code and uses no AI or telemetry at runtime.

It was built to make public-issue evidence easy to capture and audit. The free MIT-licensed Action is complete on its own. Its README separately identifies an optional $29 decision-brief service, which is not required to use the Action.
