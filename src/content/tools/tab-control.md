Tab Control helps clean up messy browser windows by closing duplicate tabs, sorting by site, grouping related pages, and pulling scattered tabs into one place.

I built it because I always end up with too many tabs, and other tools got too complicated or stopped being maintained. This one is simple, reliable, and satisfying to use, with a clean Braun-inspired feel.
