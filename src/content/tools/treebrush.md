treebrush is a TUI for browsing and managing your Git worktrees. It displays worktree details (creation date, last used, branch, linked PRs), supports fuzzy filtering, sorting, and deletion with safety confirmations. Includes optional GitHub PR integration via `gh` CLI. Perfect for developers juggling multiple branches and worktrees.
