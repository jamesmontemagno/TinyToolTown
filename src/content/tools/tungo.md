TunGo makes it easy to run your own VPN. A working tunnel can be set up in seconds using a single binary and minimal configuration. It runs on Linux, macOS, and Windows, with support for UDP, TCP, and WebSocket transports.

Simplicity does not come at the expense of performance. TunGo's dataplane hot path processes packets with zero allocations in benchmarks, while its interactive, retro-inspired TUI makes the experience approachable and enjoyable.

A small community already uses TunGo, including in countries where traditional VPN protocols are filtered by DPI. Its custom wire format avoids the well-known fingerprints of established protocols, making it more resilient in restrictive network environments.

TunGo's goal is simple: make it easy for anyone to run a fast, cross-platform VPN and help people around the world access the open internet securely.
