Wikidown is a structured markdown wiki system that lives in `/docs` of any code repository, using the same format as Azure DevOps wikis. It supports plain pages, folder-based hierarchy, and `.order` navigation files that are human-readable on disk and editable by AI agents through MCP. The wiki is browsable in Visual Studio, the web editor, or through a command-line interface, making documentation a first-class part of your codebase.
