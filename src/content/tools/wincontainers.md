WinContainers is a free, native Windows desktop app for managing containers through Microsoft's WSL Containers runtime (WSLC). It provides a focused interface for viewing, starting, stopping, restarting, and removing containers, plus image, volume, network, logs, and terminal workflows. I built it to give Windows developers a smaller, approachable alternative to Docker Desktop for local WSLC container work. The onboarding flow checks WSL2, virtualization, and WSLC prerequisites, while the app supports portable use and a self-contained installer.
