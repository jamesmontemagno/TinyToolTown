WSLC TUI turns WSLC container management into a searchable, keyboard-friendly terminal experience. It provides guided forms, command previews, local validation, safety confirmations, readable output, clipboard actions, learning topics, and release updates. I built it to make container workflows easier to discover without memorizing every command or flag. It is a focused, native Windows Go tool that stays close to the terminal while making destructive actions more deliberate.
