Yagu is a hyper-fast ripgrep-competitive Windows directory search tool for finding, previewing and bulk editing text or regex matches across large folder trees. It is a native hybrid WinUI 3 desktop and CLI app built on .NET 10, with a Rust search engine DLL for the hot content-scanning path and optional voidtools Everything integration for very fast file discovery. With AI search capabilities and zip file / image search functionality, it is also easy to use.
