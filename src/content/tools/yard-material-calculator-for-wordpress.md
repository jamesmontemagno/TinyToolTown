Yard Material Calculator adds one focused planning tool to WordPress: visitors enter area and depth, choose a landscape material, and get cubic-yard, ton, and bag estimates. It works as either a Gutenberg block or shortcode, supports imperial and metric units, and bundles all calculation code locally. I built it so gardening blogs, landscape suppliers, and DIY resource sites can offer a useful calculator without cookies, analytics, browser storage, or runtime downloads.
